A tiny program that writes the funniest one-line office joke — a single line about office life — to `/output/entry.txt` for make.fun's judge to compare two at a time.

## Run it

```sh
python3 main.py
```

Self-test (validates the 1–200 character gate, including rejection cases):

```sh
python3 main.py --self-test
```
